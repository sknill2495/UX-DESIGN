# Photoreal still image prompt

Use this order: subject and action, then setting, then composition, then camera and lens, then light, then texture and imperfection, then grade, then exclusions. Realism comes from specific optics, motivated light and small imperfections. It does not come from words like "ultra-realistic 8K masterpiece", which push toward a CG look.

```
[Who], [age, look, wardrobe with colours], [doing what, mid-action, with a specific gesture or expression].
Setting: [place, era, 3-5 concrete objects with positions, signs of life].
Composition: [shot size], [subject placement: rule-of-thirds / centred], [foreground element], [camera height: eye level / low / high], [aspect ratio].
Camera: [full-frame digital or 35mm film stock e.g. Kodak Portra 400], [focal length], [aperture], [focus point], [motion blur if any].
Light: [source + direction in frame terms], [quality: hard/soft], [colour temperature], [shadow pattern, e.g. window-pane gobo], [practicals in frame], [rim/bounce].
Texture: natural skin with pores and slight unevenness, flyaway hairs, fabric wrinkles and pilling, scuffs on furniture, dust in light beams.
Grade: [natural warm / neutral / cool], [gentle contrast], [subtle grain], [no HDR, no oversharpening].
Exclude: text, watermarks, logos, extra limbs or fingers, duplicate people, plastic skin, beauty filter.
```

For a video start frame, write the IMAGE prompt to exactly match the video's FIRST FRAME block, with the same references, positions and light, and add "mid-motion, slight motion blur on limbs".
