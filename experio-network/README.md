# Experio Network — Content Strategy & 100 Video Scripts

*Understand the Experience. Change the Perspective.*

## How to use this
1. Pick an idea number from the calendar (`09-priorities-calendar-series-growth.md`).
2. Open its file in `ideas/`. Each entry has the concept, audience psychology, strategy, sources, a timestamped Hinglish script, and Instagram + YouTube Shorts publishing assets.
3. **Re-check every claim marked [Likely] or [Verify]** against the linked source in the week you record.
4. Record → edit with the template (hook text, source card, series tag, end card) → publish → cross-post to Shorts within 48h.

## Confidence tags used throughout
- **[Certain]** documented in a primary or major source (linked).
- **[Likely]** widely reported, but wording/figures vary. Verify before recording.
- **[Verify]** a specific number or date that changes or that I couldn't confirm. Look it up before publishing.
- **[Guessing]** used only where flagged (e.g., internet theories). Never present these as fact on camera.

## Known limits
- No access to private platform analytics or proprietary algorithms. Platform guidance is from public statements as reported, and unverified "algorithm" claims are flagged in the research file.
- Audience insights are inferred from public content patterns, not scraped comments. Validate them against real comments before production.
- Engagement/share/save scores are editorial judgements for prioritization, not forecasts.
- Some ideas reference famous ads. Don't re-upload ad footage. Describe, recreate, or use licensed stock.
